        How reliable is this?

        Not very, to be honest. It can't prove anything. It just looks for habits that show up a lot in AI code (comments that repeat the code, docblocks on every function, emoji in logs, boilerplate error handling) and habits that show up a lot in human code (leftover debug prints, commented-out code, issue links, annoyed comments). Good developers write clean code too, and people clean up AI output all the time, so use the score as a reason to look closer and not as proof. Short snippets are the least reliable.
